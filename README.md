# Exploratory Data Analysis (EDA)

This repository contains my learning and practice of Exploratory Data Analysis (EDA) using Python.

## Overview

This repository includes different types of EDA techniques such as univariate, bivariate, and multivariate analysis. The goal is to understand data through various visualization methods.

Multiple datasets are used in this repository to demonstrate different types of plots. Since the focus is on learning visualization techniques, a single unified conclusion is not included.

## Topics Covered

* Univariate Analysis
* Bivariate Analysis
* Multivariate Analysis

## Visualizations Used

* Bar Plot
* Count Plot
* Line Plot
* Heatmap
* Clustermap
* Pairplot
* Histogram
* KDE Plot

## Files

* EDA_Univariate_analysis.ipynb — Covers univariate analysis
* EDA_BIVARIATE_AND_MULTIVARIATE.ipynb — Covers bivariate and multivariate analysis

## Tools and Libraries

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn

## Purpose

The purpose of this repository is to build a strong foundation in EDA and improve understanding of data visualization techniques.
